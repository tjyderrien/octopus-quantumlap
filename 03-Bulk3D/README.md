# Bulk section

To run expensive simulations prepared for BULK Si: 

1. Check inp-gs and inp-td that will be generated by run_gs and run_td.sh to generate the octopus runs. 

2. Check flood_gs.sh and run_gs.sh to generate multiple ground states.

3. Check flood_zhukov.sh and run_td.sh to generate multiple TD evolutions. 

4. Run the analysis tools prepared in 02-Slabs/plotTimeKeldysh.py, 03-Bulk/plotAll.sh and 02-Slabs/plotFinalQuantities.py.
