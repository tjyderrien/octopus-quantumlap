# Description

This folder is organized as follows. 

* Each folder corresponds to an operation.

1. First we prepare ground state of the molecule (T= 0K, no external excitatoin)

1. Second, we attempt to excite it (TD-DFT)

1. Third, we attempt to use laser on it, and see the effect. 

# Sample preparation

In this folder, sample is a super cell of silicon atoms, organized in face centered cubic structure. However, no periodic boundary condition will be applied. 

## Method

In order to consider exploring the excitation of matter, consider building a super-cell with many atoms.
