# Description

This folder is organized as follows. 

* Each folder corresponds to an operation.

1. First we prepare ground state of the molecule (T= 0K, no external excitatoin)

1. Second, we attempt to excite it (TD-DFT)

1. Third, we attempt to use laser on it, and see the effect. 

# Sample preparation

In this folder, sample is silicon 3D periodic bulk material. 

## Problem

This sample is limited to equilibrium data, as external excitation cannot work with periodic boundary conditions.

In order to consider exploring the excitation of matter, consider building another sample, rather a slab (2D periodic)  or directly a super-cell with many atoms.
